MILANO PARTECIPA — SORGENTI COMPLETI

Questa cartella contiene i file sorgenti della versione pubblicata della web app.
Il progetto usa Next.js, React, TypeScript, MySQL Aiven e Vercel Blob.

FILE PRINCIPALI
- app/page.tsx: interfaccia, proposte, profilo e pannello comitato.
- app/globals.css: stile e adattamento a smartphone/tablet.
- app/layout.tsx: struttura HTML e metadati.
- app/api/civic/route.ts: API, registrazione, allegati, voti, commenti e moderazione.
- app/api/my-comments/route.ts: elenco dei propri commenti.
- app/chatgpt-auth.ts: autenticazione della piattaforma.
- lib/civic.ts: accesso ad archivi, dati illustrativi e controlli.
- db/mysql-workbench.sql: schema iniziale MySQL per Aiven.
- db/mysql-migrations/: migrazioni incrementali MySQL.
- components/ui/: componenti grafici e accessibili.
- public/favicon.svg: icona.
- tests/security.mjs: test locali di autorizzazione e integrità.
- package.json e pnpm-lock.yaml: dipendenze e comandi.
- README.md: funzionalità, configurazione e limiti.

COME APRIRLO
1. Estrai lo ZIP.
2. Apri la cartella milano-partecipa in Visual Studio Code.
3. Installa Node.js >= 22.13.0 e le dipendenze del progetto.
   Il progetto include un lockfile pnpm: pnpm install --frozen-lockfile.
4. Il comando di sviluppo del progetto è pnpm dev.

ATTENZIONE ALL'AMBIENTE
L'archivio contiene i sorgenti della versione ospitata. Non è un sito statico
da aprire facendo doppio clic su un file HTML. Le API usano esclusivamente il
database MySQL Aiven e Vercel Blob: configura le variabili AIVEN_MYSQL_* e
BLOB_READ_WRITE_TOKEN nell'ambiente di produzione prima di eseguire scritture.
Non esiste un database locale di fallback.

Non sono inclusi node_modules, cache, credenziali, dati personali o database
in uso. Le dipendenze si reinstallano dai file di configurazione.
Le schede illustrative sono incluse nel codice.
SPID e i moduli di intelligenza artificiale non sono integrati.
